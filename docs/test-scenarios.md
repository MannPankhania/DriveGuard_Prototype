
# DriveGuard Prototype Test Scenarios

## Objective
To evaluate the DriveGuard interface and check whether it presents driver status, journey details, and safety warnings as intended.

## Test Cases

| Test Case | Action | Expected Result |
|---|---|---|
| Dashboard | Open the dashboard | Driver and journey details are displayed |
| Driver Status | View a driver state | The appropriate status is displayed |
| Safety Alert | Activate the warning state, if supported | The warning is visible |
| Start Journey | Use the start control, if interactive | The designed start interaction occurs |
| End Journey | Use the end control, if interactive | The designed end interaction occurs |
| Route Planning | Select or enter route details, if supported | Route information is displayed |

## Testing Limitations
These tests evaluate the interface only. They do not verify real-world drowsiness detection, sensor accuracy, GPS performance, or vehicle braking.

## Conclusion
These test scenarios provide a structured way to evaluate the DriveGuard prototype and identify possible interface improvements.
