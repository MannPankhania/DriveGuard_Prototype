
# DriveGuard Prototype Design

## 1. Driver Dashboard
Displays driver status, journey information, and important safety information.

## 2. Driver Status
Represents driver states such as awake or drowsy, according to the prototype design.

## 3. Drowsiness Alerts
Displays warnings for potentially unsafe driving conditions.

## 4. Journey Management
Provides controls for starting and ending a journey.

## 5. Route Planning
Presents source, destination, estimated distance, and travel time.

## 6. Safety Recommendations
Provides safety guidance, such as taking a break and resting at a safe location.

## Prototype Platform
Figma

## Future Scope
- Camera-based eye monitoring.
- Heart-rate sensor integration.
- GPS-based journey tracking.
- Real-time driver alerts.

## Project Status
This project is a UI prototype. The future-scope features require further implementation.
