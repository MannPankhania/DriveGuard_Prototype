
# DriveGuard - Driver Safety and Drowsiness Detection

## Project Overview
DriveGuard is a driver-safety prototype designed to monitor driver drowsiness and provide safety alerts during journeys. It presents driver status, journey information, route planning, and safety recommendations.

## Problem Statement
Driver fatigue and drowsiness can increase the risk of road accidents. DriveGuard proposes a user interface to display driver status and provide warnings when a driver may be drowsy.

## Objectives
- Display driver status, such as awake or drowsy.
- Show safety warnings for potentially unsafe driving conditions.
- Provide journey start and end controls.
- Display source, destination, estimated distance, and travel time.
- Suggest safe stops and appropriate safety recommendations.

## Main Features
1. **Driver Dashboard:** Displays driver status and journey information.
2. **Drowsiness Alerts:** Shows warnings for possible driver fatigue.
3. **Journey Monitoring:** Provides journey start and end controls.
4. **Route Planning:** Presents route details and estimated travel information.
5. **Safety Recommendations:** Suggests taking a break and resting at a safe location.
